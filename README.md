# KDP Launch Assistant

Independent rebuild of the visible KDP product workspace: metadata fields, discoverability drafting, print setup notes, file-name checks, readiness checklist, multiple saved product records, and JSON import/export. Product data stays in browser localStorage; selected print files are not uploaded or stored, only their filenames. No Amazon password collection, KDP account access, or automatic publishing.

No usable source was found in the matching `AWEMISSIONS/KDP-Launch-Assistant` repository. This is a reconstruction of the visible workflow. KDP requirements change; the app asks users to verify current requirements in their account before upload.
